# Sistema de Gestión de Documentos Empresariales

Este repositorio fue creado como parte de una práctica escolar para simular el almacenamiento y la administración de documentos importantes dentro de una pequeña empresa.

El objetivo del proyecto es permitir que varios integrantes del equipo puedan compartir, actualizar y organizar archivos de manera colaborativa utilizando GitHub como sistema de control de versiones. Gracias a esto, cada cambio realizado en los documentos queda registrado, evitando la pérdida de información y permitiendo consultar versiones anteriores cuando sea necesario.

## Objetivos
- Almacenar documentos importantes en un solo lugar.
- Facilitar el trabajo colaborativo entre integrantes del equipo.
- Mantener un historial de cambios y versiones de los archivos.
- Evitar la pérdida de información mediante el uso de control de versiones.

## Herramientas utilizadas
